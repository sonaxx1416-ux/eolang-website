# موقع لغة eo

موقع من صفحة وحدة: التعريف، وكيفية العمل، والشرح كامل، وملعب يشغّل eo داخل المتصفح، وأزرار تحميل `eo.exe` والإضافة.

## تشغيله على جهازك

الملعب يحمّل `eo.wasm`، والمتصفح ما يسمح بهذا لو فتحت `index.html` مباشرة. شغّله من سيرفر:

```bash
go run server.go          # http://localhost:8080
go run server.go 3000     # بورت ثاني
```

أو بـ Node: `npx serve .`

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الصفحة وكل نصوص الشرح |
| `assets/style.css` | الألوان والتصميم (نفس ألوان الفيديو) |
| `assets/app.js` | التلوين، والأمثلة المتحركة، والشرح، والملعب |
| `assets/eo.wasm` | مترجم eo نفسه، مبني لـ WebAssembly |
| `assets/eo-worker.js` | يشغّل المترجم في Worker عشان تقدر توقف أي برنامج ما يخلص |
| `downloads/` | `eo.exe` وملف الإضافة. لو حدّثتهم، حط النسخة الجديدة هنا |
| `server.go` | سيرفر صغير للتجربة |
| `tools/build-wasm.ps1` | يبني `eo.wasm` من جديد من مجلد `source` لما تعدّل اللغة |

## لو غيّرت اسم ملف الإضافة

ابحث في `index.html` عن `eo-language-1.6.1.vsix` وغيّره في المكانين.

## النشر

الموقع ملفات ثابتة بس، فيشتغل على GitHub Pages أو Netlify أو Vercel أو أي استضافة. تأكد إن الاستضافة ترسل `.wasm` بنوع `application/wasm` (أغلبها تسويه تلقائي).
