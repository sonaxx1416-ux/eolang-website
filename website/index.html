لغة eo
اكتب الكود كأنك تقرأ جملة

لغة بسيطة مكتوبة بـ Go. استدعاء بدون أقواس، وأنواع تحميك من الأخطاء، وميزة prc تشغّل أي كود بحد للوقت والذاكرة. وبأمر واحد يتحول برنامجك إلى .exe.

تحميل eo.exe 2.8 MB إضافة VS Code
Windows x64بدون تثبيتتقدر تجربها هنا في المتصفح
main.eo

      

      

    

  







  

    
الفكرة

    
وش هي eo؟

    
eo لغة برمجة للي يبي يكتب برامج حقيقية بدون ما يضيع في الرموز. الكود ينقرأ زي الكلام، والأخطاء تقول لك وش الغلط وكيف تصلحه، والبرنامج الجاهز ملف واحد تشغّله على أي جهاز ويندوز.

    

      
a b
استدعاء بدون أقواس
اكتب greet "Sara" أو add 2, 3. ولو تبي الأقواس تمشي بعد.
var r = add 2, 3
print add(10, 20)

      
@
أنواع تحميك
حدد وش المسموح بـ @ أو وش الممنوع بـ !. الشرط يتشيك عند كل تغيير.
var v @(int bool) = 5
var s !int = "Hi"

      
prc
حد للوقت والذاكرة
شغّل أي بلوك بحد. لو تعدّاه يوقف، وباقي البرنامج يكمل.
p = prc -s 1 -m 50mb {
    work()
}

      
exe
برنامج exe بأمر واحد
يتحول الكود إلى bytecode وينحط مع المشغّل في ملف واحد، والمكتبات كلها داخله.
eo build main.eo

قواميس و lambda ومكتبات
كل اللي تحتاجه لبرنامج كامل: @map و lambda و import.
print map(nums, lambda x { x * 10 })

المفسّر يمشي على الشجرة سطر سطر. أسرع طريقة وأنت تكتب.

        return count
    }

import و from

  
كل ملف .eo مكتبة. عندك lib.eo جنب ملفك:

  
# lib.eo
const PI = 3.14

func add a @int, b @int {
    return a + b
}

  
# main.eo
import lib
print lib.add(2, 3)     # 5
print lib.PI            # 3.14

from lib {add, PI}
print add(1, 2)         # 3

prc: حد للوقت والذاكرة

  
prc تشغّل بلوك كود، وإذا تعدّى الوقت أو الذاكرة اللي حددتها توقفه، وتكمل باقي البرنامج عادي.

  
p = prc -s 2 -m 50mb {
    var total = 0
    for i in range(100000) {
        total += i
    }
}
print p.status
print p.time, p.process

slow = prc -s 0.5 {
    while true {
    }
}
print slow.status
print "still running"

  

    
الخيارالمعنىمثال

    
-sأقصى وقت بالثواني-s 0.5

    
-mأقصى ذاكرة-m 10mb ، -m 512kb

    
رقم لحالهنفس -sprc 2 { ... }

  

  

    
الخاصيةوش ترجع

    
p.statusCompleted (200 OK) أو Terminated (Limit Exceeded) أو Crashed (Runtime Error)

    
p.time / p.msالمدة كنص، أو بالملي ثانية كرقم

    
p.process / p.memoryالذاكرة كنص، أو بالبايت كرقم

const MAX = 10
var secret = random(1, MAX)
var tries = 0

print "Guess a number from 1 to " + MAX

while true {
    var line = input("> ")
    if line == "" {
        print "out of input, the number was " + secret
        break
    }
    var guess = int(line)
    tries += 1
    print guess
    if guess == secret {
        print "Correct after " + tries + " tries"
        break
    } elif guess < secret {
        print "bigger"
    } else {
        print "smaller"
    }
}
